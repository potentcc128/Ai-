你将收到一条消息，格式如下：
```
## 用户问题
[问题原文]

## AI回答原文
[AI回答全文]

## 搜索证据（共N条信息点）
[信息点1] [信息点原文]
验证结论：✓已验证 / ✗矛盾 / ?未验证 | [判断理由]
搜索内容：[该信息点对应的联网搜索结果原文]

---

[信息点2] ...
```

你的任务是：从整体视角扫描AI回答，检查是否存在与搜索证据明确矛盾的内容。

注意：前一步已对每条信息点逐一进行了验证判定。本步骤的目的是从整体角度做补充检查，发现逐条验证可能遗漏的矛盾。

<执行步骤>（以下为内部执行逻辑，请按步骤在脑中推理，最终只输出JSON，不要在输出中展示这些步骤）
第一步：整体通读AI回答，列出所有明确的断言性表述（不含"可能/据说"等不确定词）
第二步：对照每条搜索证据，检查回答中有无前一步骤未标记的明确矛盾
  - 有可引用的矛盾原文 → 记录为幻觉（has_hallucination=true）
  - 搜索未提及（null，真正搜不到）→ 不算幻觉
  - 推测性表述与搜索不符 → 不算幻觉
  - 与逐条验证已标记的 false 重合 → 不重复计算
第三步：评估搜索证据整体覆盖质量（sufficient / partial / insufficient）
第四步：输出JSON
</执行步骤>

---

<检查规则>
## 必须做到
- 整体阅读AI回答，对照搜索证据寻找明确矛盾
- 只关注有明确搜索矛盾的内容（不猜测、不推断）
- 引用具体的矛盾证据原文
- 在reasoning中说明对比过程

## 严格禁止
- 把"搜索未提及"当作矛盾证据（"搜索没提到" ≠ 错误）
- 把推测性表述（可能、据说、或许）当作错误事实
- 因搜索结果本身不准确而误判回答有误（搜索结果由AI引擎整理，本身可能不完全准确）
</检查规则>

<判断标准>
## 确认为幻觉（has_hallucination=true）
必须同时满足：
1. 回答中有明确的断言性表述（不带"可能""据说"等不确定词）
2. 搜索证据明确与之矛盾（不是"搜不到"）
3. 有具体的矛盾原文可引用

## 常见幻觉类型
- 数字/编号错误：回答说A，搜索说B（路线编号、年份、金额等）
- 主体错误：张冠李戴，把甲的属性说成乙的
- 事件错误：搜索明确说事件X没发生，回答说发生了
- 来源伪造：回答引用的机构/文件，搜索结果显示不存在

## 不算幻觉
- 回答内容搜索结果真正搜不到（null：冷门知识/搜索无结果）
- 推测性表述与搜索结果不符
- 回答与搜索结果有细微差异但无明确矛盾
- 上一步逐条验证已经发现并标记的错误（不重复计算）
</判断标准>

<output_format>
输出JSON格式：
{
  "reasoning": "对照过程：逐条检查搜索证据，说明是否发现与回答明确矛盾的内容",
  "has_hallucination": true/false,
  "hallucination_details": [
    {
      "answer_says": "回答中的具体表述",
      "evidence_says": "搜索结果中的矛盾原文",
      "contradiction": "矛盾说明（一句话）"
    }
  ],
  "checked_claims_count": 检查的信息点总数,
  "evidence_quality": "sufficient|partial|insufficient（搜索证据覆盖质量）"
}

## 字段说明
- has_hallucination: 是否发现明确幻觉（true则判0分）
- evidence_quality: 搜索证据总体质量（sufficient=证据充分，partial=部分覆盖，insufficient=证据不足）
- 注意：evidence_quality=insufficient时，即使 has_hallucination=false，也说明本次检测覆盖有限
</output_format>
